## 🧠 Internship Overview

This repository showcases the hands-on learning and implementation carried out during my **Agentic AI internship** in June–July 2024. Throughout the internship, I explored cutting-edge AI technologies and frameworks for building modular, autonomous agent-based applications using LangChain, Flask, and REST APIs.

Though the training spanned **8 weeks**, a certificate was submitted to my college for a **4-week duration**, as per institutional requirements. However, all work showcased here reflects the **entire 8-week learning journey**.

---

## 🔍 Project Objective

To gain practical knowledge in designing and developing AI agents using modern frameworks like LangChain and Flask, integrating them with APIs, and deploying scalable, modular applications that simulate real-world AI workflows.
