2. Training Overview

This TR-102 Summer Industrial Training provided comprehensive, hands-on experience in Python Backend Development and the highly specialized field of Agentic Artificial Intelligence. The curriculum focused on building autonomous and intelligent systems using the cutting-edge CrewAI framework.

Program Details

Duration: 8 Weeks Intensive Training
Location: Auribises Technologies, Ludhiana (Offline Mode)
Primary Focus: Python, Flask, MongoDB, MySQL, & CrewAI Agent Development

Curriculum Modules

Module 1: Basic Programming in Python

Python fundamentals, including advanced data structures and best practices.

Module 2: Web Development with Python

Building UIs and applications using the Flask and Streamlit frameworks.

Module 3: Database Management

Data handling and CRUD operations using MongoDB and MySQL.

Module 4: Agentic AI Systems

OpenAI API integration, Prompt Engineering, and CrewAI development.
